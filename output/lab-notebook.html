RUN AN EXPERIMENT

Pick a model. Press Run.

A live marimo notebook running Sera's real optimization loop. Specialist agents tune a model's serving configuration one lever at a time, measuring every change and reverting anything that breaks the latency target or the quality floor.

Run on a Blackwell GPU

molab gives this notebook a free NVIDIA RTX Pro 6000 Blackwell — 96 GB of VRAM, in a CoreWeave sandbox — so Sera measures real vLLM servers instead of modelling them. A molab session cannot be embedded here: an iframe only ever gets a read-only WebAssembly preview with no GPU attached, so open it in its own tab.

No molab notebook is configured. Create a synced notebook on molab from notebooks/molab_lab.py in the repository, then restart the server with SERA_MOLAB_URL=https://molab.marimo.io/notebooks/<id>/app.

  1. Open the notebook and attach the GPU with the notebook specs button in its header.
  2. Press Install Sera and vLLM. Once per session.
  3. Press Download weights for the model you picked, so the transfer stays outside the timed run.
  4. Press Run Sera. Trials stream in as they land; a cold run is roughly 15–20 minutes for Qwen3-8B and 25–35 for the larger two.
