Run on a Blackwell GPU

Live molab sessionGPU not verified
Open in its own tab ↗

molab runs this notebook in a CoreWeave sandbox and can attach a free NVIDIA RTX Pro 6000 Blackwell — 96 GB of VRAM — from its notebook specs menu. A sandbox starts with no GPU, so Sera checks what is actually attached and tells you, rather than assuming. With a GPU present, Sera measures real vLLM servers instead of modelling them.

  1. On molab, create a notebook from notebooks/molab_lab.py and open it.
  2. Attach the GPU with the notebook specs button in its header. molab restarts the sandbox and gives you a new address.
  3. Copy the sandbox address from your browser's URL bar — everything up to and including .sb.molab.run.
  4. Copy the access_token value from that same URL. molab only shows it on the first open.

Host only. Paste the whole address if it is easier — Sera keeps just the origin, and lifts any ?access_token= it finds into the field below.

The access_token query parameter molab puts in the URL the first time the notebook opens. If it has scrolled out of the address bar, reopen the notebook from molab's file list.

This token is stored on this machine. Sera writes it to .local/molab.json, owner-read-only, so the local relay can reach the sandbox. It is never sent back to the browser and never appears in /api/molab/status. Anyone holding it can run code in your sandbox, so do not do this on a shared machine. Disconnect erases it.

Reaching the sandbox…

Sera is checking the token, opening the kernel socket through the local relay, and asking the sandbox what hardware it has. A few seconds is normal.
