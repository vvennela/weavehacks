# Unmeasured LIBXSMM kernel directions for the next board

## Baseline facts

The pinned baseline calls the full 512x512 LIBXSMM kernel once from [`baseline/kernel.c`](../cpu-libxsmm-generator-2026-09-25/baseline/kernel.c#L769-L780). It enters SME once. In its assembly, `Llibxsmm_64` allocates a 128 KiB stack buffer and `Llibxsmm_78` fills that buffer before the FMOPA loop (`baseline/kernel.c` lines 69-75 onward). The optional N=32 panel helper is embedded at line 823 but the baseline does not call it.

Prior results are not evidence of a winner. The 16-call N=32 panel candidate passed correctness but was not promoted: paired differences were mixed in Low Power (−3.1%, +0.5%, +2.2%) and Automatic (−10.9%, +17.7%, +14.1%). The fixed-size C SME candidate was also not promoted. Padding A slices to 272 bytes lost two of three paired comparisons in each mode and was rejected. The Automatic baseline itself failed held-out confirmation. See the two `search/result.json` files in `cpu-libxsmm-panel-swarm-2026-09-25` and `cpu-libxsmm-automatic-2026-09-25`.

## Distinct hypotheses for the board

1. **Use N=64 output-row panels instead of sixteen N=32 panels.** This requires a separately host-prepared `(M,N,K)=(512,64,512)` FP32 beta-zero helper. After that helper is supplied, the source edit is to change the N=512 wrapper loop at [`trial-001/source/kernel.c`](../cpu-libxsmm-panel-swarm-2026-09-25/search/trial-001/source/kernel.c#L774-L783) to advance `r` by 64 and call it eight times. Keep `A_arg=A+r*512`, `B_arg=B`, and `C_arg=C+r*512`. This is legal because it partitions disjoint output rows; the host must confirm the pinned generator emits the exact shape and validate the helper before the Sera run. **Hypothesis:** fewer calls and SME start/stop transitions may offset the larger per-call panel work. It is unmeasured; N=32 results do not predict it. Astra's 180-second implementation call has no filesystem, compiler, or generator tools, so it cannot prepare this helper itself.

2. **Split the other output axis with an M=32 helper.** This requires a separately host-prepared `(32,512,512)` helper. Once supplied, cover the original output in sixteen column bands. For band `c`, pass column-major `A_arg=B+c`, `B_arg=A`, and `C_arg=C+c`, with leading dimensions still 512; this computes the matching 32 rows of `Cᵀ=BᵀAᵀ`. This changes which operand is panelized and how C is written, unlike the tested N=32 row-band layout. **Hypothesis:** its pack and cache behavior may differ. The host must verify the M-tail generator path and guarded output boundaries before timing. Astra can make the wrapper edit within its implementation cap only after the validated helper is present; correctness and gains remain unknown.

3. **Use a transpose-aware full-shape kernel with a matching prepacked input layout.** The pinned generator supports transpose descriptor flags, but a flag-only change is mathematically wrong for the existing row-major pointers. Host preparation must supply a generated full-shape variant and its verified descriptor/layout contract before Sera edits the wrapper to pack the matching input; all packing work must remain inside the timed call. **Hypothesis:** packing once into a reusable layout may cost less than the current internal stack packing at `Llibxsmm_78`. This needs preparation beyond the existing 512x32 helper, which Astra cannot generate. The host should verify the mapping, beta-zero/output semantics, and correctness before a timed Sera run. This is separate from the failed 272-byte scratch-padding experiment, which changed scratch spacing without removing packing.

One level of Strassen is mathematically compatible with FP32 GEMM only if its changed rounding stays within the fixed tolerance. It needs host preparation for suitable subproduct helpers; the available primitive is 512x32x512, not the 256x256 subproducts Strassen needs. The implementation also adds seven products, temporary sums, and new packing. Include it as a research alternative only if the board wants to investigate it, with helper preparation and validation explicitly assigned outside Astra's tool-limited call. Do not assume it is a win.

These are alternatives for board ranking, not a selected experiment or performance claim. Keep the full product, FP32, single-thread, frozen-hill, correctness, paired-control, promotion, and power-state rules unchanged.
